# 🚀 Portal Multiverso — Rick and Morty

## 📖 Sobre o projeto

O **Portal Multiverso** é uma aplicação web desenvolvida como atividade acadêmica da disciplina de **Web Development Front-End**.

O objetivo do projeto é aplicar conhecimentos de HTML, CSS e JavaScript, realizando a integração com uma API pública para apresentar informações sobre personagens do universo de Rick and Morty.

A aplicação permite visualizar personagens por meio de cards dinâmicos, com informações obtidas diretamente da API.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo da página.
- **CSS3:** estilização, organização visual e responsividade.
- **JavaScript:** manipulação do DOM, interatividade e consumo da API.
- **Fetch API:** realização de requisições HTTP para obtenção dos personagens.
- **GitHub Pages:** hospedagem e publicação do site.

## ✨ Funcionalidades

O projeto apresenta as seguintes funcionalidades:

- Exibição dinâmica de personagens.
- Imagens e informações individuais dos personagens.
- Pesquisa de personagens pelo nome.
- Filtros por status.
- Paginação para navegação entre personagens.
- Layout responsivo para diferentes tamanhos de tela.
- Integração com uma API pública.

## 🔗 API utilizada

O projeto utiliza a **Rick and Morty API**, uma API pública que disponibiliza informações sobre personagens, episódios e localizações do universo da série.

**Documentação oficial:**  
https://rickandmortyapi.com/documentation

**Endpoint utilizado:**

`https://rickandmortyapi.com/api/character`

Os dados são obtidos por requisições HTTP utilizando o método `fetch()` do JavaScript.

A resposta é processada em formato JSON e utilizada para criar os cards dinamicamente no DOM.

## 💻 Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Localize o arquivo `index.html`.
4. Abra o arquivo em um navegador atualizado.
5. Utilize as funcionalidades de pesquisa, filtros e navegação.

**Observação:** é necessário estar conectado à internet para carregar os dados da API.
